# ល្បែងសិក្សា អូរតាប្រុក (Ou Ta Pruk Learning Games)

កម្មវិធីល្បែងសិក្សាអន្តរកម្មតាមបែប Wordwall ទំនើប ជាមួយប្រព័ន្ធ AI បង្កើតសំណួរស្វ័យប្រវត្តិ។

## 🎮 ប្រភេទល្បែងរួមមាន៖
1. **ផ្គូផ្គងរូបភាព / ពាក្យ (Matching Pairs)**
2. **ចាប់គូពាក្យត្រូវ (Match Up)**
3. **កម្រងសំណួរ (Quiz)**
4. **បើកប្រអប់អាថ៌កំបាំង (Open The Box)**
5. **កង់បង្វិលសំណាង (Random Wheel)**
6. **ស្វែងរកពាក្យក្នុងតារាង (Word Search)**
7. **វាយសត្វកណ្តុរ (Whack-a-Mole)**

## 🚀 របៀបបើកដំណើរការលើកុំព្យូទ័រ (Local Server)
```bash
python server.py
```
បន្ទាប់មកបើក Browser ចូលទៅកាន់: `http://localhost:8000`

## 🌐 របៀបបង្ហោះលើ GitHub Pages
1. Upload ឯកសារទាំងអស់ទៅកាន់ GitHub Repository របស់អ្នក
2. ចូលទៅ **Settings** > **Pages**
3. ត្រង់ **Branch** ជ្រើសរើស `main` (root) រួចចុច **Save**
4. រង់ចាំ ១-២ នាទី អ្នកនឹងទទួលបាន Link គេហទំព័រផ្ទាល់ខ្លួន!
